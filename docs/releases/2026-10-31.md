## 執行環境與驗證

- Windows 10/11 x64，需 Microsoft Edge WebView2 Runtime、.NET Framework 4.8；語音回覆需 Windows 中文朗讀語音。
- MiniCPM5-2B Q4_K_M 以 CPU 執行；語音辨識為 faster-whisper-small INT8，語音回覆使用 Windows SAPI。
- 原生無標題列視窗，外框為 28DIP 圓角。
- App ZIP 的 22,168 份檔案均通過逐檔 SHA-256 與 CRC 校驗，另附模型通過 SHA-256 校驗，內容符合既有發行清單。
- 自動下載工具已在同一台 Windows 主機，使用預先存放的已驗證下載檔案，完成解壓縮與模型放置；還原後 22,169 份檔案逐檔 SHA-256 全數符合原始清單。完整大型檔案的線上下載流程尚未另行重跑。
- 既有 App 已完成 17 項特定技術檢查。8GB 實機、完整 50 組任務、真人使用者研究及跨電腦相容性驗證仍待完成。
