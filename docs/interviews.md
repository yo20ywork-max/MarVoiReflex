# 使用者需求訪談規劃

研究對象為6–8位具有社群行銷或小型商家營運經驗的人員，每人約20–30分鐘。目前訪談尚未執行。

## 研究程序

說明研究目的、退出方式及錄音選擇。以U01–U08代碼記錄，身分與聯絡資料分開保存。訪談使用合成或去識別素材，公開成果採匿名摘要。

## 訪談題綱

1. 最近一次準備社群貼文時，如何尋找圖片、文案與成效截圖？
2. 素材通常儲存在哪些位置？整理流程有哪些步驟？
3. 最常遇到的問題是什麼？上一週發生幾次、每次花多少時間？
4. 是否遇過重複檔案或活動分類錯誤？造成哪些影響？
5. 如何命名活動、日期與資料夾？哪些操作需要人工確認？
6. 分類預覽需要包含哪些資訊？來源、目的地與數量是否清楚？
7. 哪些場合適合語音或文字操作？
8. 是否願意持續使用？對付費方式、預算與功能有何期待？
