# 訪談規劃：先問 6–8 位真的有做行銷的人

**狀態：尚未招募、尚未訪談、沒有研究結果。** 每人約 20–30 分鐘，對象有社群行銷或小型商家營運經驗。先問現況，再展示，避免引導對方說產品很好。

## 訪談前

說明研究目的、可隨時跳題或退出；錄音需另行同意。訪談用 U01–U08 代碼，身分／聯絡方式另放私人名冊；公開文件只放去識別摘要。請受訪者用虛構或已去識別素材，不提供客戶、帳號、營收或未公開活動資料。

## 要問的話

1. 你最近一次準備社群貼文，是怎麼找圖片、文案和成效截圖的？
2. 素材通常放在哪些地方？請用測試資料示範一次。
3. 哪個步驟最常卡住？上一週發生幾次、每次花幾分鐘？
4. 有沒有找錯、重複檔案或分錯活動？實際造成什麼影響？
5. 你會怎麼命名活動、日期和資料夾？哪些情況不能自動搬？
6. 若先顯示搬移清單再按確認，你看得懂嗎？還想知道什麼？
7. 你願意用語音還是文字？什麼環境不方便說話？
8. 什麼情況下你願意持續使用／付費？不預設一定要訂閱。
