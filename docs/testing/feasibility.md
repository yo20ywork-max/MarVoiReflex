## 8GB 實機驗收方法

在真正 8GB、沒有獨顯的 Windows 電腦，記錄 CPU 型號、RAM、作業系統、電源模式、頁面檔與背景負載。使用相同 GGUF／ASR SHA-256、4執行緒、4096 context、單一並行。冷啟動與暖機分開，每題同步採樣程序族 RSS、系統可用 RAM、commit 與分頁狀態；延遲記完整使用者路徑。先跑小批安全題，再完成 50 組與三輪不同口語素材，保留全部失敗。不要在 32GB 主機只限制模型記憶體就宣稱 8GB 實機通過。
