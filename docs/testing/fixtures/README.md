準備時使用真正有效的各格式檔案，不能只換副檔名；用純色測試圖片與自寫文字即可。逐檔建立 SHA-256 manifest，保留模型看不到的人工標準答案。B集改活動名稱與內容，保留相同日期邊界。三輪口語另換檔名與說法，先封存再執行。

異常資料另建：目的地同名不同內容、預覽後更改來源、缺少資料夾、過期計畫；測試 symlink／junction 時僅連到同一隔離測試根目錄的無敏感檔，測後依明確路徑清理。正式人工比較前由兩人獨立核對題目與答案，保留分歧處理紀錄。
