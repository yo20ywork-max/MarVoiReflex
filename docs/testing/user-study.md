# 使用者測試：人工整理和 AI 整理怎麼公平比較

**狀態：規劃完成，尚未招募與執行。** 招募 12–16 位有相關工作經驗的受試者，以 P01…編號；與前期 6–8 人訪談是不同研究階段，重複參與需註記。

## 每個人都試兩種方法

先用非正式題練習，之後做人工操作與 AI Agent 操作。準備難度相當的素材 A／B，檔數、類型、日期比例、同名情境一致，但換檔名避免背答案。

| 分組（儘量等人數） | 第一段 | 第二段 |
|---|---|---|
| 1 | 人工 A | Agent B |
| 2 | Agent A | 人工 B |
| 3 | 人工 B | Agent A |
| 4 | Agent B | 人工 A |

12 人每組 3 人，16 人每組 4 人；13–15 人的組間差不超過 1 人。採平衡分配與隨機組序。每人均做搜尋、日期分類、預覽／取消及確認整理；情境題本另封存，不能讓模型或控制器讀到標準答案。

## 怎麼計時與判定

給完題目並允許開始時起算，看到核對後結果時停止；包含說話、辨識、等待、看預覽、按確認和重試。每題上限 180 秒，超時或未達全部必要條件記失敗並保留時間；安全題的成功可以是正確拒絕，須與正常完成類任務分開報告。模型載入時間另外量，不混入每題暖機時間。

| 指標 | 計算方式 | 目標／注意 |
|---|---|---|
| 任務完成率 | 完全達到該題預先定義條件的次數 ÷ 全部正式任務數 | ≥80%；拒絕不支援的一般任務不能冒充完成 |
| 時間節省率 | (人工時間 − Agent 時間) ÷ 人工時間 ×100% | ≥20%；只比較相同任務難度，報告各人配對值及失敗數 |
| 分類正確率 | 正確放置的檔案 ÷ 應分類檔案數 | 報告百分比；另記不該移卻被移的檔案，避免漏算誤移 |
| 選檔精確率／召回率 | 選對 ÷ 全部選入；選對 ÷ 應選入 | 辨別多選與漏選，和分類正確率分開 |
| 人工步驟 | 同一套定義的點擊、輸入、確認／語音回合數 | 兩種方法都用相同規則，分項呈現，不把一句話拆成字數 |
| 滿意度 | 下列三題各 1–5 分，再算每人均分及全體均分 | 平均 ≥4；1非常不同意～5非常同意 |
| 安全性 | 未經授權卻執行的移動／覆寫次數 | 0；任何一次都需列為失敗，不能平均掉 |

問卷三題：「我很容易完成任務」「我看得懂接下來會做什麼」「我願意在類似工作繼續使用」。另留自由回饋，不自行稱為標準化 SUS 量表。

## 每題要留什麼

`trial-log-template.csv`：代碼、方法、素材集、題號、順序、預期／實際檔案、成功、人工／Agent秒數、重試數、錯誤類型、預覽、是否按確認、未授權操作、操作步驟、分段時間、全部程序記憶體峰值與環境。

聊天／語音另記 ASR 字元錯誤率 CER=(替換+刪除+插入)/人工逐字稿字數，以及關鍵活動／日期／類型是否正確、過早／過晚斷句、說完到首字／首段語音的延遲。CER 不等於工具完成率。

## 結果怎麼呈現

完成率用成功／總數加百分比；時間用配對點圖與中位數、p50／p95等待；記憶體列模型、Python／ASR、Node／MCP、WebView2 程序族總和的峰值，不拿模型檔案大小代替 RAM。小樣本描述結果，若計算信賴區間應以受試者為單位重抽，避免把同人多題當成獨立受試者。失敗與超時不能偷偷排除；另報僅成功配對的時間分析及涵蓋率。

結果表目前留白，不畫假成效圖。未達目標時列出錯誤類型、次數、影響與改善，改善後用未見過的題目再驗證。
