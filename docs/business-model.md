# 商業模式畫布 BMC：九件事情先想清楚

目前全部屬待驗證的商業假設；沒有已確定的訂閱市場或收入。

| 構面 | 白話意思 | 本專題的初步想法 | 怎麼確認 |
|---|---|---|---|
| 客戶區隔 | 誰最需要 | 小型商家的社群行銷人員 | 訪談 6–8 人、確認素材整理頻率 |
| 價值主張 | 幫他省下什麼 | 減少找檔／整理時間及分錯檔案 | 人工與 Agent 的同難度任務比較 |
| 通路 | 怎麼接觸他 | 小型商家社群、校內成果展示、專題說明頁 | 記錄來源與願意試用人數 |
| 客戶關係 | 如何教他使用 | 簡單教學、預覽確認、問題回報 | 觀察首次任務完成與常見問題 |
| 收益來源 | 誰願意怎麼付費 | 免費試用／一次買斷／訂閱皆為選項 | 問實際預算與持續需求，不先認定訂閱可行 |
| 關鍵資源 | 少了什麼就做不成 | 本機模型、CPU 推論、工具控制器、測試素材與團隊 | 技術可行性與 8GB 實機驗證 |
| 關鍵活動 | 團隊最重要的工作 | 訪談、素材整理、安全驗證、使用者測試 | 每週紀錄、每兩週展示 |
| 關鍵夥伴 | 誰能幫忙 | 願意試用的商家／行銷人員、指導教授、工具社群 | 以實際同意為準，未宣稱合作成立 |
| 成本結構 | 會花在哪裡 | 開發時間、測試設備、維護／支援、散布與儲存 | 記工時與實際帳單；尚未估出毛利 |

主要價值始終是「降低小型商家行銷素材整理時間與操作錯誤」。聊天、模型參數與工具數量是實作方法，不直接當成顧客願意付錢的理由。
