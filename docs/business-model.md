# 商業模式畫布

以下為九大構面的初步規劃。需求、使用意願及付費模式將透過訪談與試用驗證。

| 構面 | 規劃內容 | 驗證方法 |
|---|---|---|
| 客戶區隔 | 小型商家的社群行銷人員 | 訪談6–8人，確認素材整理頻率與工作方式 |
| 價值主張 | 減少素材搜尋與分類時間，降低檔案整理錯誤 | 人工與Agent的同難度任務比較 |
| 通路 | 商家社群、校內成果展示、專題說明頁 | 記錄接觸來源與試用意願 |
| 客戶關係 | 操作教學、分類預覽、問題回報 | 觀察首次使用與常見問題 |
| 收益來源 | 免費試用、一次買斷或訂閱 | 訪談預算、使用頻率與付費需求 |
| 關鍵資源 | 本機模型、CPU推論、工具控制器、測試素材與團隊 | 技術可行性與8GB實機測試 |
| 關鍵活動 | 需求訪談、系統開發、安全驗證與使用者測試 | 每週進度紀錄與雙週展示 |
| 關鍵夥伴 | 試用商家、行銷人員、指導教授與工具社群 | 合作與試用安排 |
| 成本結構 | 開發工時、測試設備、維護支援與散布儲存 | 工時及實際成本紀錄 |

產品價值以行銷素材整理的時間與錯誤改善衡量；商業可行性分析將於取得訪談與使用數據後更新。
