# MVP 功能規格

本階段聚焦行銷素材整理，開發目標為16週內可操作、可驗證的 Windows 原型。

| 核心功能 | 操作內容 | 狀態與驗收條件 |
|---|---|---|
| 指定工具啟動 | 開啟預先設定的 App、瀏覽器與活動資料夾 | 開發規劃中；執行對象及參數符合白名單 |
| 素材搜尋與分類 | 依活動、類型、本週或明確起迄日搜尋 | 已有基本流程；選檔結果與人工標準答案一致 |
| 預覽與確認 | 顯示來源、目的地與數量，確認後搬移 | 已有基本流程；取消保持原檔，同名檔停止，搬移後逐檔核對 |

## 支援範圍

- 檔案格式：PNG、JPG、JPEG、WEBP、TXT、MD；單檔最多32MB。PDF、Office文件及影音未納入本版。
- 操作區域：App的 `workspace/materials` 工作區。
- 活動條件：依檔名關鍵字辨識；成效截圖以圖片及檔名標記處理。
- 類型條件：目前分為圖片與文字兩類。精確PNG、JPG或MD篩選列於待開發項目，對應測試M13–M15。
- 日期條件：使用檔名中的 `YYYYMMDD`。本週為當地日期所屬週一至週日，含起迄日；無日期檔案不列入本週篩選。
- 分類位置：固定為 `materials/已整理/圖片/` 與 `materials/已整理/文案/`。活動或週別多層目錄列於後續規格。
- 執行授權：搬移計畫包含ID與檔案雜湊，由畫面確認後執行。
- 異常處理：越界路徑、同名檔、來源變動及不支援需求，進入拒絕或澄清流程。批次中途失敗時回報實際完成與未完成項目；整批自動回復未納入本版。

## 開發階段

1. 工具啟動、資料夾搜尋與素材清單。
2. 分類、搬移前預覽、操作確認、結果驗證與異常回報。
3. 中文語音、多步驟規劃、錯誤處理與8GB實機驗證。

## 後續擴充

自動發文、行銷文案生成與跨平台帳號操作。

## 完整任務驗收

匯入測試素材後，在任務模式提出整理需求；核對預覽的來源、目的地及數量，按確認後檢查目的檔案存在、來源狀態、內容雜湊及結果摘要。取消、同名檔、來源變動與越界案例分別驗證。
